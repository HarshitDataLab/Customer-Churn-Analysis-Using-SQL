# Customer Churn Analysis Using SQL

## Project Overview
Analyzed customer churn data using MySQL to identify churn trends, revenue loss, and customer behavior.

## Tools Used
- MySQL
- SQL

## SQL Concepts
- Aggregations
- GROUP BY
- CASE Statements
- Subqueries
- Window Functions

## Key Insights
- Calculated churn rate.
- Identified high-risk customers.
- Analyzed churn by city and contract type.
- Measured revenue lost due to churn.
